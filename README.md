## About the system

A polar vault stores sealed boxes of crop seeds deposited by registered
institutions (gene banks, universities, governments). Each box holds seed
samples of one species. The vault has several freezer chambers, and staff
handle deposits, withdrawals and monitoring. The vault is a custodian, not an
owner: depositors keep ownership of their boxes.
